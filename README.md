# Auto-Immune AI-Powered Secure Data Management for EMRs (AI DataLock)

Final-year project, Phase II, April 2026. S.A. Engineering College, Anna University.
Team: Adhithya Nithin R, Adithyan K, Karnesh E J. Supervisor: Mrs. P. Ruba Sudha.

## What it does
- Patients, doctors, hospitals, labs and an admin each get their own login.
- Patients upload reports, which are encrypted before storage, and share them with selected doctors or staff.
- Each upload, share and unauthorized access attempt is added to a hash-linked JSON blockchain log.
- The report proposes attribute-based encryption, Isolation Forest anomaly detection and proxy re-encryption on top.

## Stack
Python Flask, MySQL, HTML/CSS/JavaScript (Bootstrap), RSA, Fernet, PHP for the blockchain log.
