Auto-Immune AI-Powered Secure Data Management for EMRs (AI DataLock)

Final-year project, Phase II, April 2026 · Team of 3 · Python Flask, MySQL, RSA, Fernet, JSON blockchain

A web platform for storing and sharing electronic medical records securely. Patients upload encrypted reports, share them with chosen doctors and staff, and every upload, share and unauthorized access attempt is written to a hash-linked blockchain log. The report also designs hierarchical attribute-based encryption, Isolation Forest anomaly detection and proxy re-encryption on top of this.

Smart Inventory & Order Management System

Web application · Python, Flask, MySQL, HTML, CSS, JavaScript

A web application for managing products, suppliers, customers and orders. Stock updates automatically when an order is placed, cancelled or restocked, and the dashboard flags products at or below their reorder level. A MySQL database holds products, orders and a history of every stock change, and the dashboard shows orders, inventory levels and sales reports.

Limits: no user login yet, and the order form takes one product per order. Runs locally with sample data only.

Emoji Generator from Text using NLP

ML Lab mini project, September 2023 · Team of 3 · Python, Hugging Face Transformers

Reads a sentence, detects the emotions in it with a pre-trained DistilRoBERTa emotion classifier, and returns matching emojis. Any emotion scoring 0.20 or higher is kept, so a sentence with mixed feelings returns several emoji sets.

Limits: the emotion model is pre-trained by others and used as is. The emoji sets are hand-written. No accuracy score is reported, only example outputs.
